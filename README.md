# 🇱🇦 老挝语学习 - Lao Learner

专为在老挝做生意/工作的中国人打造的老挝语学习 PWA 应用。

## ✨ 功能特色

### 📝 字母表学习
- 27个老挝语辅音完整收录
- 按中辅音/高辅音/低辅音分类
- 点击查看详细信息、近似发音、示例单词

### 🎵 声调学习
- 6个声调详细讲解
- 声调符号对照表
- 发音技巧提示

### 📚 实用词汇
- 做生意必备词汇（数字、货币、砍价）
- 日常交流用语
- 交通出行、餐饮点餐
- 中老对照 + 近似拼音

### 💬 场景对话
- 市场砍价
- 打车出行
- 餐厅点餐
- 商务谈判

### 🃏 闪卡复习
- 随机抽取词汇测试
- 翻转卡片学习
- 学习结果统计

## 🚀 技术栈

- **前端框架**: React 18 + TypeScript
- **构建工具**: Vite
- **样式**: Tailwind CSS
- **部署**: GitHub Pages (PWA)

## 📱 使用方式

1. 手机浏览器打开网址
2. 点击"添加到主屏幕"即可当 App 使用
3. 支持离线使用

## 🛠️ 本地开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 📦 部署

项目已配置 GitHub Actions，推送到 `main` 分支后自动部署到 GitHub Pages。

### 手动部署步骤：

1. Fork 或克隆本仓库
2. 在 GitHub 仓库设置中启用 GitHub Pages
3. 选择 "GitHub Actions" 作为部署源
4. 推送代码即可自动部署
